# 安全边界（开发版）

- 用户选择的文件才进入工具；无遥测、账号、网络服务代码。FFmpeg 目前限制输入协议为 file/pipe，但恶意本地容器/文档仍可能引用其他本地资源；LibreOffice/Tesseract/第三方库不能据此被保证不联网。正式版必须用 OS 权限限制、网络隔离、进程树限制及安全更新，当前独立 worker 不是沙箱。
- 文件处理库可能存在漏洞。ZIP 解压检查 Windows 保留名称、路径冲突、条目类型、条目数与解压大小。输入和输出目录拒绝符号链接及重解析点，递归扫描跳过重解析目录。Windows 中文长路径已实测，junction 验收与其他引擎的资源上限仍待补齐。
- 文件原样保留；报告包含路径/元数据，仍可能是敏感数据。批量复制与工作流可能占用较多磁盘；系统异常可能留下暂存目录。无可靠安全删除保证。取消是协作式的。
- 加密格式 FBXENC v1：7 字节 magic/version、16 字节随机盐、12 字节随机 nonce、密文、16 字节 GCM tag；头作为 AAD，密钥由 scrypt(N=32768,r=8,p=1) 派生。解密先写入进程持有的临时文件，认证通过后写入任务输出。原文件名与数据长度可见，解密需要原密码，格式的独立审计仍待完成。
- 密码不应进命令行、历史、日志、预设。CLI 建议 stdin，不要写有密码的 request.json。历史可能含路径/错误信息，用户可清除。应审查第三方错误输出与 Windows 本地 ACL。
- PDF 加密/解密不是去除恶意内容。PDF 真正的底层脱敏还未实现。图片遮盖重新编码像素、移除常见元数据；不代表对所有信息的安全匿名化。格式签名只是识别提示，不能检测病毒。
- 不自动安装未知引擎，不允许运行任意外部命令作为工作流参数。新增插件必须设计权限、签名与可撤销安装。
