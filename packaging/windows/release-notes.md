## 万象 0.8.1

- **沉浸式窗口边框**。万象标题、工具入口和窗口按钮共用一条顶栏，顶栏和细边框随浅色、深色或系统主题切换。
- **窗口操作**。拖动顶栏空白处可移动窗口，双击可最大化或还原，拖动边缘与四角可调整大小。窗口按钮沿用随鼠标移动的柔和反光。

下载 `FormaBox-0.8.1-Windows-x64-Full-Setup.exe`，双击进入中文安装向导。支持 Windows 10（1809 及以上）和 Windows 11 x64。已有旧版需先卸载。可使用同页的 SHA-256 校验文件核对下载。

完整安装包内置 Qt、Python、FFmpeg、Tesseract（含英文和简体中文语言包）及 LibreOffice。音视频处理、OCR 和 Office 转 PDF 可以直接使用。

安装目录的 `engines/NOTICES.txt` 列有内置引擎出处和许可证。FFmpeg 与 Tesseract 对应源码附件供开发者查阅，LibreOffice 26.8.3.1 的源码见其上游镜像。[LibreOffice 源码目录](https://mirrors.ibiblio.org/libreoffice/src/26.8.3/)
