## 万象 0.8.0

- **重新整理工具区**。默认显示 12 个常用工具。左栏按图片、PDF、视频、音频、文档与数据、文件与隐私分类，搜索可直接查全部工具。
- **更新浅色和深色界面**。按钮用柔和的薄雾反光，随鼠标移动。页面工作台、预设、结果和重命名等弹窗也采用同一套按钮。
- **腾出工作区**。任务中心和工作流可以收起。添加工作流步骤或启动新任务时，对应区域自动展开。

下载 `FormaBox-0.8.0-Windows-x64-Full-Setup.exe`，双击进入中文安装向导。支持 Windows 10（1809 及以上）和 Windows 11 x64。已有旧版需先卸载。可使用同页的 SHA-256 校验文件核对下载。

完整安装包内置 Qt、Python、FFmpeg、Tesseract（含英文和简体中文语言包）及 LibreOffice。音视频处理、OCR 和 Office 转 PDF 可以直接使用。

安装目录的 `engines/NOTICES.txt` 列有内置引擎出处和许可证。FFmpeg 与 Tesseract 对应源码附件供开发者查阅，LibreOffice 26.8.3.1 的源码见其上游镜像。[LibreOffice 源码目录](https://mirrors.ibiblio.org/libreoffice/src/26.8.3/)
