## 万象 0.4.0

- **任务结果面板**。查看每项输出以及文件大小。目标压缩还会显示原始大小、目标值和是否达标。可以打开输出，也能勾选一批文件直接用作当前输入。
- **右键发送到万象**。安装后在 Windows 资源管理器中选中一个或多个文件，使用「发送到 → 万象（FormaBox）」加入输入列表，再选择工具处理。若右键菜单未显示「发送到」，先打开「显示更多选项」。卸载会移除该入口。
- **批量重命名预览**。支持文字替换、按 EXIF 拍摄日期命名，以及调整输入顺序后编号。确认前可对照原名、新名和冲突提示。处理结果写入副本。
- **多步工作流预设**。保存、移除并一键运行整套步骤。内置「图片缩放、压缩并合成 PDF」工作流。

下载 `FormaBox-0.4.0-Windows-x64-Setup.exe` 后双击打开中文安装向导。支持 Windows 10（1809 及以上）和 Windows 11 x64。已有旧版需先卸载。安装包内置 Qt 和 Python，提供 SHA-256 校验文件，暂未签名。
