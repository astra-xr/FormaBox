## 万象 0.2.0

- **PDF 页面工作台**。把 PDF 和图片拖进工作台，用缩略图调整顺序、旋转、插入或移除页面，再导出一份新的 PDF。支持未加密的 PDF 和单帧图片，最多编辑 32 个文件、300 页。
- **引擎设置**。选择 LibreOffice、FFmpeg 和 Tesseract 的程序路径，在万象里试跑并保存。LibreOffice 可直接用样本验证 Word 转 PDF。
- **拖入推荐**。按输入格式和文件数量推荐操作，例如把 Word 转成 PDF、压缩图片，或把 PDF 和图片混合编排。
- 修复 ZIP 压缩后丢失空目录、工作流进度在换步时倒退，以及无效取消标记留下临时目录的问题。

从下方下载 `FormaBox-0.2.0-Windows-x64-Setup.exe`，双击打开中文安装向导。支持 64 位 Windows 10（1809 及以上）和 Windows 11。安装包内置 Qt 和 Python，提供 SHA-256 校验文件，暂未签名。
