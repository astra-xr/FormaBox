## 万象 0.3.0

- **PDF 限大小导出**。在页面工作台查看选中页的压缩前后对照，并核对实际文件大小。未达目标时可选择是否保存试压结果。独立的「PDF 按大小压缩」工具也可直接使用。
- **扫描 PDF OCR**。使用 Tesseract 为扫描页添加可搜索、可复制的文字层。保留原页面外观并跳过已有可提取文字的页面。需要相应语言包，识别准确度受扫描质量、字库和版面影响。
- **常用预设**。内置报名照压缩、Word 转 PDF、扫描件转可搜索 PDF。可保存自己的工具参数，并在拖入匹配文件后一键运行。

PDF 限大小压缩和扫描 OCR 支持未加密的 PDF，每份最多 300 页、256 MiB。

下载 `FormaBox-0.3.0-Windows-x64-Setup.exe`，双击打开中文安装向导。支持 64 位 Windows 10（1809 及以上）及 Windows 11。安装包自带 Qt 和 Python，提供 SHA-256 校验文件，暂未签名。
