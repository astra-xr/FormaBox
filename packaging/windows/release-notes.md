## 万象 0.7.0

- **视频批量抽帧**。设置间隔、每段视频的张数上限和图片最长边，从首帧开始依序导出 PNG。拖入视频即可从推荐操作打开。
- **三个引擎随完整安装包提供**。内置 FFmpeg、Tesseract（含英文和简体中文语言包）、LibreOffice，加上 Qt 和 Python 运行环境。安装万象后即可直接处理音视频、执行 OCR 和将 Office 文件转换成 PDF。

下载 `FormaBox-0.7.0-Windows-x64-Full-Setup.exe`，双击进入中文安装向导。支持 Windows 10（1809 及以上）和 Windows 11 x64。已有旧版需先卸载。可使用同页的 SHA-256 校验文件核对下载。

安装目录的 `engines/NOTICES.txt` 列有内置引擎出处和许可证。FFmpeg 与 Tesseract 对应源码附件供开发者查阅，LibreOffice 26.8.3.1 的源码见其上游镜像。[LibreOffice 源码目录](https://mirrors.ibiblio.org/libreoffice/src/26.8.3/)
