## 万象 0.5.0

- **PDF 添加页码**。设定页码范围、起始编号、位置与边距。每份文档独立计数，生成的页码可复制。
- **PDF 文字水印**。调整文字、字号、位置与透明度。Windows 可使用系统字体添加中文水印，原有 PDF 文字和矢量内容继续保留。
- **PDF 裁白边**。按毫米设定四边裁切宽度，支持旋转页面。裁切调整可见范围，裁去的底层内容仍在文件中。

拖入 PDF 会推荐这些工具。可一次处理多份未加密 PDF，或将它们与其他处理步骤串成工作流。输出为副本。

下载 `FormaBox-0.5.0-Windows-x64-Setup.exe` 后双击打开中文安装向导。支持 Windows 10（1809 及以上）和 Windows 11 x64。已有旧版需先卸载。安装包内置 Qt 和 Python，提供 SHA-256 校验文件，暂未签名。
