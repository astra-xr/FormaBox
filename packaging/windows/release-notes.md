## 万象 0.6.0

- **字幕格式转换**。批量将 SRT 转为 WebVTT，或将 WebVTT 转为 SRT。保留时间和多行正文，保留常见粗体、斜体和下划线。跨格式时省略专属布局与样式。
- **字幕时间轴平移**。输入毫秒偏移，负数提前，正数延后。跨过零点的字幕从 0 秒开始，完全早于 0 秒的条目会移除。
- **字幕提取纯文本**。生成 UTF-8 TXT，可以给每段加上起始时间。

拖入 SRT 或 WebVTT 即可看到推荐工具。支持同时处理多份字幕或串成工作流，输出为新文件。字幕处理无需 FFmpeg。

下载 `FormaBox-0.6.0-Windows-x64-Setup.exe` 后双击打开中文安装向导。支持 Windows 10（1809 及以上）和 Windows 11 x64。已有旧版需先卸载。安装包内置 Qt 和 Python，提供 SHA-256 校验文件，暂未签名。
